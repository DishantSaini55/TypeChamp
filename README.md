## ✨ Features

- 🏎️ **Real-Time WPM Tracking**: Watch your Words Per Minute update live as you type.
- ⏱️ **Timer**: Challenge yourself against the clock.
- 🎨 **Modern UI**: A beautiful, distraction-free interface built using Tailwind CSS.
- 🔄 **Refresh on the Fly**: Instantly generate new text blocks to keep practicing.
- 🛡️ **Anti-Cheat Measures**: Disables text selection and copying to ensure true typing tests.

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/DishantSaini55/TypeChamp.git
   ```
2. **Navigate into the directory**
   ```bash
   cd TypeChamp
   ```
3. **Run the app**
   Just double-click on `index.html` to open it in your default web browser, or use a tool like VS Code Live Server.
